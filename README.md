# Yeshiva Van Tracker – Frontend

A React Native web application for tracking student van usage at a yeshiva (school). This app allows the user to log trips, manage vehicle bookings, and keep track of trip-related expenses.

## ⚠️ Project Status

This project is **actively under development** and not fully functional yet. Many features are still being implemented, and the system is subject to significant changes as I refine the requirements and architecture.

## 🎯 Overview

Yeshiva Van Tracker is designed to solve a real organizational problem: managing a shared vehicle across many users. The app provides a centralized place to:

- **Log van trips** with details about drivers, date, and time
- **Manage trip requests and bookings** to coordinate van usage
- **Track expenses** associated with trips (gas, tickets, tolls, maintenance, etc.)
- **View trip history and analytics** to understand usage patterns

Instead of managing everything through text messages and spreadsheets, this app brings structure and clarity to the entire process.

## ✨ Features

### Currently Implemented
- User authentication (login)
- Trip logging interface with driver and trip details
- Expense tracking and recording
- Trip and expense history views
- React Native with Expo for cross-platform support (web, iOS, Android)

### In Progress
- Trip filtering and search
- Expense categorization and reports
- Role management (students vs. staff/admins)
- Input validation

### Planned Features
- Automated expense splitting and settlement calculations
- Advanced trip analytics and usage reports
- Trip request and booking system
- Push notifications for booking requests and updates
- Calendar view for van availability
- Photo upload for trip documentation (tickets, tolls)
- Strike system for tracking user violations
- Mobile-optimized UI refinements
